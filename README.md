# Traveller1File
.NET File applications

This may end up being a collection of single file C# scripts for command line things. 

## How to use
### Framework and language
This will run on Macs, Linux and PCs. You will to install .NET if not already there (while PCs will most likely already have it installed, Macs may or may not). Just like python or other languages and frameworks, .NET Core is a framework that is now available for Macs and Linux as well as the PC.  If not on your machine justsearch for the Microsoft .NET for your system.
### Usage
There should be an option to copy the files to your local machine. Download them somewhere. Then simply:

**dotnet *file* **

To run the UWP translater:

**donbtet UWPTranslate**
